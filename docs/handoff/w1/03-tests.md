- ترس مجهول في `only=` يُرفض.

### الحلقة
- دورة أداة كاملة: استدعاء → تنفيذ → نتيجة في المحادثة → جواب نهائي.
- `max_steps` و`max_tool_calls` يتوقفان ويسمّيان السبب.
- اسم مخترع / ترس خارج المسموح / JSON تالف / وسائط ليست كائنًا — كلها أخطاء مُعادة، والحلقة تكمل.
- `SpendCapExceeded` و`GatewayError` يعبران.
- قائمة الرسائل الأصلية لا تُعدّل.
- `usage` يُجمع عبر الدورات.

### الـ Gateway
- بلا أدوات: جسم الطلب **مطابق** للقديم (اختبار انحدار صريح).
- مع أدوات: `tools` + `tool_choice="auto"`.
- `content: null` + استدعاءات = نجاح.

- `last_tool_calls` تُصفَّر بين الردود.
- `complete()` القديم لم يتغير.
