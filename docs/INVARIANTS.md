# INVARIANTS — ما لا يجوز كسره

> **أي تغيير يخالف بندًا هنا = مرفوض، بغض النظر عن الفائدة.**
> الكسر المتعمّد يحتاج قرارًا موثّقًا في `DECISIONS.md` + موافقة صريحة.

## الحالة

| # | القاعدة |
|---|---|
| I1 | انتقالات الحالة **فقط** عبر `TRANSITIONS` في `manifest.py`. لا كتابة `state` مباشرة. |
| I2 | `archived` حالة نهائية. لا خروج منها. |
| I3 | `failed` لا يُستأنف إلا عبر `resurrect()` أو قرار بشري. |
| I4 | تجاوز `max_revisions_per_capsule` → `failed`. لا حلقة لا نهائية. |

## الموافقة (TOCTOU)

| # | القاعدة |
